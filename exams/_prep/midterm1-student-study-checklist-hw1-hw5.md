# Midterm 1 Study Checklist (From HW1-HW5)

Use this as a quick self-check before the exam.

## 1) Core Must-Do Skills

- [ ] I can separate **what is measured** from **what is inferred** (O -> M -> I).
- [ ] I carry units through my work and catch dimensional mistakes.
- [ ] I can use ratio/scaling forms without re-deriving everything.
- [ ] I always include a one-line sanity check (bigger/smaller, faster/slower, brighter/fainter).

## 2) Gravity and Orbits (HW1-HW2)

- [ ] I can use Kepler/Newton to infer mass from period + semi-major axis.
- [ ] I can compare orbital speed and escape speed and explain the \(\sqrt{2}\) factor.
- [ ] I can classify bound vs unbound from energy sign.
- [ ] I can explain why “centripetal force” is not a separate physical force.

## 3) Light and Spectra (HW2-HW4)

- [ ] I can identify source conditions from emission/absorption/continuous spectra.
- [ ] I can compute and interpret Doppler shift direction and velocity.
- [ ] I can use wavelength-energy relationships correctly (including trend direction).
- [ ] I can explain OBAFGKM line strengths using temperature/excitation, not abundance myths.

## 4) Distance, Luminosity, Temperature, Radius (HW3-HW4)

- [ ] I can go from parallax to distance quickly.
- [ ] I can apply inverse-square law to compare fluxes.
- [ ] I can use Wien’s law to infer temperature from \(\lambda_{\text{peak}}\).
- [ ] I can use Stefan-Boltzmann scaling to infer radius trends.
- [ ] I can explain how reddening/extinction biases inferred \(T\) and \(R\).

## 5) Binary Masses + Magnitudes (HW5)

- [ ] I can compute total binary mass in solar units.
- [ ] I can use SB2 amplitudes to get mass ratio and component masses.
- [ ] I can explain why inclination matters and why eclipsing binaries are better constrained.
- [ ] I can use distance modulus in both directions (find \(d\), find \(M\)).
- [ ] I can reason from a magnitude offset to a distance ratio (main-sequence fitting idea).

## 6) Full-Chain Readiness (Capstone Level)

- [ ] I can complete one full inference chain without prompt-hunting:
  observed quantities -> model -> inferred physical properties.
- [ ] I can name at least one key assumption and one likely uncertainty/bias direction.

## 7) 30-Minute Final Drill Plan

- [ ] 10 min: one orbital/binary mass problem (with units + sanity check).
- [ ] 10 min: one distance modulus + one parallax/flux scaling problem.
- [ ] 10 min: one short conceptual explanation (misconception repair + O->M->I).

## If You Get Stuck

- [ ] Write: **Given**, **Find**, **Equation**, **Units check**, **Sanity check**.
- [ ] Ask: what trend should happen physically before calculating?
- [ ] Switch to ratio form if constants are slowing you down.
