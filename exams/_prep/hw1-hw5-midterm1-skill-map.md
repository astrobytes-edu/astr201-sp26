# Midterm 1 Homework Skill Map (HW1-HW5)

This document maps each homework problem to likely Midterm 1 skills/outcomes and gives targeted review actions.

## Midterm 1 Outcome Legend

- O1: Distinguish direct observables from model-dependent inferences (O → M → I).
- O2: Use units/dimensional analysis as a correctness filter.
- O3: Apply scaling and ratio methods efficiently.
- O4: Use orbital dynamics and energy reasoning (bound/unbound, escape/orbit speed, Kepler/Newton).
- O5: Use light/spectra models (Kirchhoff, Doppler, atomic transitions, blackbody limits).
- O6: Connect parallax, flux, luminosity, and distance consistently.
- O7: Use Wien + Stefan-Boltzmann to infer temperature/radius and interpret trends.
- O8: Interpret HR-diagram position using mass/radius/temperature/luminosity logic.
- O9: Infer stellar masses from binary observables (period, semi-major axis, RV amplitudes, inclination).
- O10: Use magnitude and distance-modulus reasoning (including offsets and fitting).
- O11: State assumptions, uncertainties, and likely bias direction.
- O12: Execute a full multi-step inference chain with sanity checks.

## Quick Readiness Heuristic

A student is likely midterm-ready if they can do all of the following without prompt-hunting:

- Solve one binary mass problem and explain what was measured vs inferred.
- Solve one distance-modulus problem in both directions (find \(d\) and find \(M\)).
- Run one full chain: parallax/flux/color -> \(L,T,R\) with one uncertainty statement.
- Pass a dimensional/unit check and one reasonableness check on every computed answer.
